# Punch In Punch Out Frontend

React and Vite frontend for the Punch In Punch Out app.

## Run

```powershell
npm install
npm run dev
```

## Vercel

```text
Root Directory: FE
Build Command: npm run build
Output Directory: dist
```

Set this environment variable:

```text
VITE_API_URL=https://YOUR-BACKEND-RENDER-URL.onrender.com
```
